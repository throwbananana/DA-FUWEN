# 雾野领主 Godot 原型

基于《策划项目计划书_MDA心流强化版》实现的 Godot 4.6 单局垂直切片。项目重点验证三件事：

- 棋盘随机性能否通过步数修正和路线选择变成可控博弈。
- 怪物战斗、抓捕与基地岗位分配能否互相反哺。
- AI 领主是否能通过人格化抢点和 Boss 竞争形成压力。

## 当前可玩内容

- 半开放棋盘推进：掷骰、`+1/-1` 修正、重掷、基地支援、路线选择。
- 怪物系统：原创 6 种怪物、属性克制、2v2 回合战、野外捕缚、Boss 战。
- 基地系统：前线 / 苗圃 / 熔炉 / 研究所 / 休整岗位分配，3 座建筑升级。
- AI 对手：3 种人格之一随机开局，自动抢据点、跑资源、争 Boss。
- 胜负条件：8 回合内先到 10 威望，或回合结束后威望更高者获胜。

## 运行方式

1. 用 Godot 4.6 打开仓库根目录。
2. 主场景已经配置为 `res://scenes/main.tscn`。
3. 直接点击运行即可开始。

## 玩法说明

- 开局先点 `基地管理`，把伙伴安排到前线或生产岗位。
- 点击 `掷骰` 后，地图上会高亮所有可达终点。
- 可消耗专注使用 `+1`、`-1`、`重掷` 或 `基地支援`。
- 落到战斗格会进入回合战；把野怪压低血量后可尝试捕缚。
- 回合结束时，基地按岗位产出资源，据点按占领方结算收益。
- 第 5 回合开放 `裂辉尖塔`，Boss 奖励足以直接改写优势。

## 验证命令

语法 / 场景检查：

```powershell
godot --headless --path . --quit
```

最小交互 smoke test：

```powershell
godot --headless --path . --script res://scripts/smoke_test.gd
```

## 主要文件

- `scenes/main.tscn`：主场景与弹窗层。
- `scripts/main.gd`：回合流程、AI、节点结算、胜负判定。
- `scripts/battle_panel.gd`：战斗、状态、捕缚。
- `scripts/base_panel.gd`：基地岗位和建筑升级 UI。
- `scripts/game_data.gd`：地图、怪物、技能、事件、建筑和 AI 数据。
